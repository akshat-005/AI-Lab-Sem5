## Setup

1. Install Python 3 from [python.org](https://www.python.org/downloads/).
2. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

3. Open the repository folder:

   ```bash
   cd AI-Lab
   ```

No additional libraries are required unless specified in the program.

## Running the Programs

Run the required Python file from the terminal:

```bash
python USN_Week1_TicTac_Vaccum.py
```

If `python` does not work, use:

```bash
python3 USN_Week1_TicTac_Vaccum.py
```

Replace the filename with the file you want to run. Follow any instructions displayed by the program.

## Submission Guidelines

- Include the code for all assigned programs in the submission.
- Add screenshots showing the output of each program to the `outputs` folder.
